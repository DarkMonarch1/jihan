This workspace contains a simple personal portfolio website inspired by the layout of edwardh.io. that I built for my own portfolio but you can take my code or fork it to make your own.

Files
index.html – main page structure and content.
styles.css – page styling, layout, colors, and responsive design.
script.js – interactive behavior for skill tabs and slider values.
How it works
The hero section and about section are defined in index.html.
The skills area has tabs for categories and fixed percentage bars for languages.
The page includes a boot animation and monitor-style scroll container inspired by edwardh.io.
Changing the text in index.html can make the content your own.
The look can be customized in styles.css if you want a different color scheme.
